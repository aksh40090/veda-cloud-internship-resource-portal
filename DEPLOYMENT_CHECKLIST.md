# Submission Evidence Checklist

- [ ] GitHub repository is public
- [ ] README.md present
- [ ] Cloudflare Pages deployment succeeded
- [ ] Published portal URL works
- [ ] Search/filter works
- [ ] Worker API returns JSON
- [ ] R2 screenshot, if R2 is used
- [ ] Custom domain screenshot, if a domain is configured
- [ ] HTTPS is visible in the browser
- [ ] Architecture diagram included

Do not fabricate screenshots or URLs. Capture evidence from the actual deployment.
